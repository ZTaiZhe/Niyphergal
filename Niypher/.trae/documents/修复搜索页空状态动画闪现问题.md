## 问题原因
搜索页空状态元素在渲染时会先无动画直接显示，然后消失再执行渐入动画，造成闪现问题。

## 修复方案
修改 [styles.css](file:///d:/.A素材/Niypher/Niypher/src/css/styles.css) 中的 `.animate-empty-in` 类，添加 `visibility: hidden` 确保元素初始完全不可见，动画开始时才显示。

## 具体修改
在 `.animate-empty-in` 类中添加 `visibility: hidden`，并在动画关键帧中添加 `visibility: visible`：

```css
.animate-empty-in {
    opacity: 0;
    visibility: hidden;
    animation: emptyStateFadeIn 0.4s ease-out forwards;
}

@keyframes emptyStateFadeIn {
    from {
        opacity: 0;
        visibility: visible;
        transform: scale(0.9);
    }
    to {
        opacity: 1;
        visibility: visible;
        transform: scale(1);
    }
}
```

这样确保元素在动画开始前完全不可见，避免闪现问题。
