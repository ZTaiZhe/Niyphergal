# 集成SearchGal功能到引力搜索页（功能嵌套方案）

## 1. 设计原则
- **保留现有UI**：完全采用网站已有设计，不进行大规模界面改动
- **功能嵌套**：在现有引力搜索页基础上添加SearchGal核心功能
- **风格统一**：确保新功能与现有设计风格一致
- **最小侵入性**：对现有代码进行最小改动

## 2. 实现方案

### 2.1 现有UI结构分析
- **搜索框**：id="gal-search"，已有回车键事件监听
- **搜索按钮**：onclick事件触发搜索
- **搜索结果区**：当前未实现，需添加
- **底部信息**：已包含SearchGal原仓库链接

### 2.2 功能嵌套实现

#### 2.2.1 搜索逻辑实现
- 替换现有alert提示，实现实际搜索函数
- 设计异步搜索逻辑，调用SearchGal搜索API
- 添加搜索状态管理（加载中、完成、失败）

#### 2.2.2 搜索结果展示
- 在现有搜索框下方添加结果展示区域
- 采用与现有网站一致的卡片式设计
- 每个结果卡片显示：游戏名称、平台特性（标签）、来源平台
- 结果卡片包含链接，可跳转到对应平台

#### 2.2.3 搜索状态反馈
- 在搜索按钮上添加加载状态（如旋转图标）
- 搜索完成后显示结果数量
- 搜索失败时显示错误提示

#### 2.2.4 平台特性标注
- 免登录：绿色标签
- 需魔法：黄色标签
- 特殊条件：白色标签
- 采用现有网站标签样式

## 3. 实施步骤

1. **修改搜索按钮点击事件**：替换alert，调用实际搜索函数
2. **添加搜索状态管理**：
   - 搜索按钮添加加载动画
   - 显示搜索结果数量
   - 处理搜索失败情况
3. **实现搜索结果展示区域**：
   - 在现有搜索框下方添加结果容器
   - 设计与现有风格一致的结果卡片
   - 实现结果卡片的动态生成
4. **集成SearchGal搜索逻辑**：
   - 设计API调用函数
   - 实现结果数据处理
   - 添加平台特性标签
5. **优化搜索体验**：
   - 添加搜索防抖，避免频繁请求
   - 实现搜索历史记录（使用LocalStorage）
   - 添加结果分页（如果需要）

## 4. 技术要点
- 使用现有网站的CSS类和样式
- 采用异步JavaScript处理搜索请求
- 实现事件委托处理动态生成的结果卡片
- 添加适当的错误处理和重试机制
- 确保响应式设计，适配现有网站的移动端布局
