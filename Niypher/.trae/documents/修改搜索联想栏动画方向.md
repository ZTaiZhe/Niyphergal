## 修改搜索联想栏动画方向

### 问题分析
1. 当前联想栏使用左右滑动动画，不符合用户要求的从上到下动画
2. 分页切换时动画方向会改变，不符合用户要求的保持不变

### 解决方案
1. **添加从上到下的动画定义**
   - 在CSS中添加`slideInFromTop`和`slideOutToBottom`动画
   - 添加对应的动画类

2. **修改渲染逻辑**
   - 修改`renderPage()`方法，始终使用从上到下的进入动画
   - 忽略`navigationDirection`变量对动画的影响

3. **修改分页切换逻辑**
   - 统一分页切换时的动画效果
   - 下一页：旧项向下移出，新项从上移入
   - 上一页：旧项向下移出，新项从上移入

### 具体修改步骤
1. 在CSS动画定义部分添加：
   ```css
   @keyframes slideInFromTop { from { opacity: 0; transform: translateY(-50%); } to { opacity: 1; transform: translateY(0); } }
   @keyframes slideOutToBottom { from { opacity: 1; transform: translateY(0); } to { opacity: 0; transform: translateY(50%); } }
   .animate-slide-in-top { animation: slideInFromTop 0.5s cubic-bezier(0.25, 0.46, 0.45, 0.94) forwards; }
   .animate-slide-out-bottom { animation: slideOutToBottom 0.5s cubic-bezier(0.25, 0.46, 0.45, 0.94) forwards; }
   ```

2. 修改`renderPage()`方法：
   - 将动画类从根据方向变化改为固定使用`animate-slide-in-top`

3. 修改分页切换方法：
   - `goToPreviousPage()`：将旧项移出动画改为`animate-slide-out-bottom`
   - `goToNextPage()`：将旧项移出动画改为`animate-slide-out-bottom`
   - 移除对`navigationDirection`的依赖

4. 确保容器显示时的动画正确

### 预期效果
- 联想栏弹出时，所有项从上到下平滑进入
- 分页切换时，无论方向如何，旧项向下移出，新项从上移入
- 保持动画的流畅性和一致性
