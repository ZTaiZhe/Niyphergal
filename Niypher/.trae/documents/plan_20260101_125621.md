# 游戏详情页优化计划

## 问题分析
用户要求修改游戏详情页的多个方面，包括顶置大图样式、内容定位、亚克力卡片统一和下载板块结构调整。需要对现有页面模板进行全面优化，使其符合用户的设计要求。

## 解决方案

### 文件：index.html

1. **顶置大图优化**：
   - 将顶置大图从玻璃卡片中移出，使其向上、左、右突破卡片边界
   - 添加渐变效果，使大图边缘逐渐消失
   - 类似网易云播放页专辑照片大图模式

2. **内容定位调整**：
   - 将背景层以上各部分起始位置向下移动三分之一个屏幕
   - 使用 `pt-[33vh]` 类实现内容向下移动

3. **亚克力卡片统一**：
   - 将简介板块和下载板块的背景改为统一的亚克力质感圆角卡片
   - 使用现有的 `glass-card` 类实现统一风格

4. **下载板块重构**：
   - 将官方资源与非官方资源放在同一个亚克力卡片中
   - 中间用淡灰色细线隔开
   - 官方资源前用较大字体注明"官方"二字
   - "官方"二字使用粉色荧光效果强调

### 具体修改

1. **修改页面整体结构**：
   - 重构 `detail` 函数的 HTML 输出
   - 添加顶置大图容器
   - 调整内容定位

2. **优化顶置大图样式**：
   - 添加全屏大图容器
   - 应用渐变效果
   - 调整 z-index 确保正确显示

3. **统一亚克力卡片样式**：
   - 为简介板块添加 `glass-card` 类
   - 为下载板块添加 `glass-card` 类
   - 调整内部间距和边距

4. **重构下载板块**：
   - 合并官方和非官方资源
   - 添加分隔线
   - 添加"官方"标签和粉色荧光效果

## 预期效果
- 顶置大图突破卡片边界，边缘渐变消失
- 所有内容向下移动三分之一个屏幕
- 简介和下载板块使用统一的亚克力卡片样式
- 下载板块中官方资源与非官方资源清晰区分
- "官方"二字使用粉色荧光效果强调

## 代码修改示例

1. **修改顶置大图结构**：
   ```html
   <div class="fixed top-0 left-0 w-full h-[60vh] overflow-hidden z-0">
       <img src="${res.cover}" class="w-full h-full object-cover">
       <div class="absolute bottom-0 left-0 w-full h-32 bg-gradient-to-t from-white to-transparent dark:from-gray-800 dark:to-transparent"></div>
   </div>
   ```

2. **调整内容定位**：
   ```html
   <div class="animate-fade-in pb-10 pt-[33vh] relative z-10">
       <!-- 内容 -->
   </div>
   ```

3. **重构下载板块**：
   ```html
   <div class="glass-card p-5 mb-6">
       <div class="space-y-3">
           <div class="font-bold text-lg text-pink-600 text-shadow-glow">官方资源</div>
           <!-- 官方资源列表 -->
           <div class="border-b border-gray-200 my-3"></div>
           <!-- 非官方资源列表 -->
       </div>
   </div>
   ```

4. **添加粉色荧光效果**：
   ```css
   .text-shadow-glow {
       text-shadow: 0 0 10px rgba(236, 72, 153, 0.5);
   }
   ```
