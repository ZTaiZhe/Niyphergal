# 搜索页空状态修改计划

## 需求

1. 将搜索页空状态中的"浏览分类"按钮改为"回到首页"按钮
2. 删除清除筛选条件按钮
3. 空状态时不单独弹出，直接显示在原本应该显示搜索结果的地方

## 修改位置

* `src/js/pages/search.js` - renderEmptySearch 函数

## 修改内容

1. 将"浏览分类"按钮改为"回到首页"按钮，点击后调用 `router.push('home')`
2. 删除清除筛选条件按钮
3. 空状态内容直接渲染在搜索结果容器中，不使用弹窗

## 验证

* [ ] 空状态显示"回到首页"按钮

* [ ] 点击按钮后页面跳转到首页

* [ ] 清除筛选条件按钮已删除

* [ ] 空状态直接显示在搜索结果区域
