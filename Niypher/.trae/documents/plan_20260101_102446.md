# 修复搜索联想栏焦点事件处理问题

## 问题分析
- 当焦点从联想栏移开后再移回（满足联想栏收起后再次点击搜索框但不键入或删除字符时），联想栏不会再次响应
- 无法就失焦前已键入且保留在搜索框里的字符再次弹出关联搜索

## 根本原因
- 当前实现只监听了 `input` 事件，当用户输入或删除字符时才会触发搜索建议
- 缺少 `focus` 事件监听器，当搜索框获得焦点时，没有重新检查当前输入并显示搜索建议
- 当用户点击搜索框外部时，会调用 `clearSuggestions()` 隐藏搜索建议，但当用户再次点击搜索框时，由于没有触发 `input` 事件，所以搜索建议不会重新显示

## 解决方案

### 文件：index.html

1. **添加焦点事件监听器**：
   - 在 `SearchSuggestion.init()` 方法中添加 `focus` 事件监听器
   - 当搜索框获得焦点时，检查当前输入并显示搜索建议
   - 调用现有的 `handleInput` 函数来处理当前输入

### 具体修改

1. **修改 `init` 方法**：
   - 在搜索输入框上添加 `focus` 事件监听器
   - 当搜索框获得焦点时，获取当前输入值并调用 `handleInput` 函数

2. **确保焦点事件正确处理**：
   - 当搜索框获得焦点且输入值不为空时，显示搜索建议
   - 当搜索框获得焦点且输入值为空时，不显示搜索建议
   - 确保焦点事件不会与其他事件冲突

## 预期效果
- 当用户点击搜索框外部，搜索建议隐藏
- 当用户再次点击搜索框时，搜索建议根据当前输入值重新显示
- 不需要用户重新键入或删除字符，搜索建议就能再次弹出
- 提高了用户体验，使搜索功能更加流畅

## 代码修改示例

```javascript
// 初始化搜索建议功能
init: function() {
    const searchInput = document.getElementById('header-search');
    const suggestionContainer = document.getElementById('search-suggestions');
    
    // 输入事件监听
    searchInput.addEventListener('input', (e) => {
        const query = e.target.value.trim();
        this.handleInput(query);
    });
    
    // 焦点事件监听
    searchInput.addEventListener('focus', (e) => {
        const query = e.target.value.trim();
        this.handleInput(query);
    });
    
    // 键盘事件监听
    searchInput.addEventListener('keydown', (e) => {
        this.handleKeydown(e);
    });
    
    // 点击外部关闭搜索建议
    document.addEventListener('click', (e) => {
        if (!e.target.closest('.relative.w-full.max-w-2xl.mx-auto')) {
            this.clearSuggestions();
        }
    });
}
```
