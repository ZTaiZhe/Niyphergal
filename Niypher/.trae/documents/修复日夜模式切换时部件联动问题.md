# 修复日夜模式切换时部件联动问题

## 问题分析
当前日夜模式切换时，各部件的过渡效果可能不一致，导致某些容器或框架的轮廓在切换过程中短暂暴露。主要原因包括：
1. 部分容器元素缺少过渡效果
2. 不同元素的过渡时间不一致
3. 某些元素的过渡属性不完整

## 解决方案

### 1. 统一所有容器元素的过渡效果
为所有可能暴露框架的容器元素添加一致的过渡效果，确保它们在主题切换时同步变化：

```css
/* 为所有容器元素添加统一过渡 */
header, main, nav, section, div, .glass-card, #search-suggestions {
    transition: all 0.4s ease, background-color 0.4s ease, border-color 0.4s ease, box-shadow 0.4s ease;
}
```

### 2. 确保所有body.dark样式都有过渡效果
检查并修复所有`body.dark`前缀的样式，确保它们都有适当的过渡属性：

```css
/* 例如，为dark模式下的搜索结果滚动条添加过渡 */
body.dark #search-suggestions::-webkit-scrollbar-track,
body.dark #search-suggestions::-webkit-scrollbar-thumb {
    transition: background-color 0.4s ease;
}
```

### 3. 修复特定元素的过渡问题
- 为header元素添加过渡效果
- 为nav元素添加过渡效果  
- 确保所有fixed定位元素有过渡效果

### 4. 确保主题切换是原子操作
在ThemeManager.toggleTheme()方法中，确保dark类的添加/移除是同步的，没有延迟操作影响过渡效果。

## 实施步骤
1. 为所有主要容器元素添加统一的过渡效果
2. 检查并修复所有body.dark样式的过渡属性
3. 确保header和nav等关键元素有过渡效果
4. 测试主题切换效果，确保没有框架暴露

## 预期效果
- 日夜模式切换时，所有元素同步过渡
- 没有容器或框架轮廓在切换过程中暴露
- 整个切换过程平滑自然
