# 评分机制和分布图实施计划

## 1. 数据模型设计

### 1.1 扩展评论数据结构
- 在`DB.comments`数组中为每条评论添加`rating`字段，用于存储评分
- 示例：`{ user: "UserA", text: "资源速度很快，感谢分享！", avatar: "", rating: 5 }`

### 1.2 为游戏资源添加评分字段
- 在`DB.resources`的每个游戏对象中添加评分相关字段：
  - `rating`: 平均评分
  - `ratingCount`: 评分人数
  - `ratingDistribution`: 评分分布数据（1-10分的数量）

## 2. 评分显示实现

### 2.1 顶部评分显示
- 在游戏详情页顶部添加评分显示，包括星级和分数
- 实现"查看评分分布"链接，点击显示评分分布图
- 设计参考提供的设计图，显示为`★★★☆☆ 3.7`格式

### 2.2 评分分布图
- 实现评分分布柱状图，显示1-10分的评分数量
- 设计为悬浮弹窗，点击"查看评分分布"时显示
- 包含评分人数和各分数段的具体数量

## 3. 打分功能实现

### 3.1 评论框评分组件
- 在评论框右上方添加星级评分组件
- 实现点击星星进行评分的交互
- 评分范围为1-5星

### 3.2 评分与评论关联
- 实现评分与评论的关联，提交评论时同时提交评分
- 允许仅评分不评论

## 4. 权限控制
