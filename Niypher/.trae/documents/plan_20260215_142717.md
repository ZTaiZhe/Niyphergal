## 修改目标
修改搜索页的进入动画效果：
- **进入搜索页时**：当前页面保持不动，搜索页从下方平移进入
- **离开搜索页时**：保持现有的滑动动画不变

## 修改内容

### 1. styles.css - 添加从底部滑入动画
```css
@keyframes slideInFromBottom { 
    from { opacity: 0; transform: translateY(100%); } 
    to { opacity: 1; transform: translateY(0); } 
}
.animate-slide-in-bottom { 
    animation: slideInFromBottom 0.5s cubic-bezier(0.25, 0.46, 0.45, 0.94) forwards; 
}
```

### 2. renderer.js - 修改动画逻辑
在动画判断逻辑中添加搜索页特殊处理：
- 进入搜索页时：使用 `animate-slide-in-bottom`，旧页面不执行动画
- 离开搜索页时：保持现有的滑动动画逻辑
- 其他页面之间的切换：不受影响
