## 当前环境状态

## 部署选项

### 选项 1: 使用 GitHub Actions 自动部署（推荐）

1. 将代码推送到 GitHub 仓库
2. GitHub Actions 会自动：
   - 安装依赖 (`npm ci`)
   - 构建项目 (`npm run build`)
   - 运行 Lighthouse 审计
   - 部署到 Cloudflare Pages

**查看**: [.github/workflows/deploy.yml](file:///d:\.A素材\Niypher\Niypher\.github\workflows\deploy.yml)

### 选项 2: 本地手动部署

在有 Node.js 环境的机器上执行：

```bash
# 1. 进入项目目录
cd d:\.A素材\Niypher\Niypher

# 2. 安装依赖
npm install

# 3. 构建项目
npm run build

# 4. 部署到 Cloudflare Pages
npx wrangler pages deploy dist --project-name=niyphergal
```

### 选项 3: 直接部署源代码（无需构建）

如果只是想快速部署当前源代码（不包含最新的修改）：

```bash
npx wrangler pages deploy . --project-name=niyphergal
```
