# 修复论坛按钮激活状态不显示粉色的问题

## 问题原因
论坛按钮使用 `<div class="forum-icon">匿</div>`，而CSS激活样式只针对 `<i class="ri-xxx">` 图标，导致激活时"匿"字不会变成粉色。

## 修复方案

### 1. 添加CSS样式
为 `.forum-icon` 添加激活状态的粉色样式，包括明亮和黑暗模式：

```css
.nav-item.active .forum-icon {
    color: #ec4899 !important;
}

body.dark .nav-item.active .forum-icon {
    color: #ec4899 !important;
}
```

### 2. 可选：增强JavaScript逻辑
在 `updateNav()` 函数中添加对 `.forum-icon` 的处理，使其在激活时有更明显的视觉反馈（如加粗）。

## 修改位置
- **CSS**：在第668行后添加新的样式规则
- **JavaScript**：可选，在第3989行后添加 `.forum-icon` 的处理逻辑

## 预期效果
- 点击论坛按钮时，"匿"字会变成粉色
- 与其他三个导航按钮保持一致的激活状态样式
- 不影响任何现有功能
