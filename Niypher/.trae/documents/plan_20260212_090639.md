# 搜索联想栏功能优化计划

## 1. 功能修改

### 1.1 键盘左右键翻页后焦点管理
- 修改 `handleKeydown` 方法中的左右箭头处理逻辑
- 翻页后将 `currentIndex` 设置为 0，`isSelecting` 设置为 true
- 调用 `updateSelection()` 更新选择状态，确保焦点在列表第一项

### 1.2 输入框焦点时的左右箭头行为
- 修改 `handleKeydown` 方法中的左右箭头处理逻辑
- 只有当 `isSelecting` 为 true 时，左右箭头才触发翻页
- 当焦点在输入框时，让默认行为发生（控制光标移动）

### 1.3 联想栏高度调整
- 修改 CSS 样式，确保联想栏高度足够显示所有内容，包括分页按钮
- 确保左右翻页键能完整露出

## 2. 技术实现

### 2.1 修改 `search.js` 中的键盘事件处理
- 更新 `ArrowLeft` 和 `ArrowRight` 事件处理逻辑
- 添加焦点状态判断，区分输入框焦点和联想项焦点
- 实现翻页后自动聚焦到列表第一项的功能

### 2.2 调整 CSS 样式
- 更新 `#search-suggestions` 的样式，确保高度足够
- 确保分页按钮区域有足够的空间

## 3. 测试验证
- 测试键盘左右键翻页后焦点是否回到列表第一项
- 测试焦点在输入框时，左右箭头是否控制光标移动
- 测试联想栏高度是否足够，分页按钮是否完整露出
- 测试所有边界情况，确保功能正常
