# 搜索关联页左右平移切换动画实现

## 需求分析
将搜索关联页的动画效果改为类似于功能页之间的左右平移切换效果，保持键入搜索栏时的弹出动画不变。

## 实现计划

### 1. 修改 CSS 样式
- 确保 `#search-suggestions` 容器支持左右平移动画
- 移除当前的 `scaleY` 过渡，改为支持 `translateX` 过渡

### 2. 重构 renderPage 方法
- 移除当前的缩放动画逻辑
- 实现基于导航方向的左右滑动效果：
  - **下一页（next）**：新内容从右侧滑入，旧内容从左侧滑出
  - **上一页（prev）**：新内容从左侧滑入，旧内容从右侧滑出
- 使用页面切换容器模式，类似于功能页切换

### 3. 优化动画时序
- 使用 `requestAnimationFrame` 确保动画流畅
- 协调进入和退出动画的时序
- 保持与功能页切换一致的动画时长和缓动函数

### 4. 保持初始弹出动画
- 确保键入搜索栏时的联想栏弹出动画不变

## 关键代码点

1. **动画类使用**：利用现有的 `animate-slide-in-left`、`animate-slide-in-right`、`animate-slide-out-left`、`animate-slide-out-right` 动画类
2. **导航方向**：根据 `navigationDirection` 决定动画方向
3. **容器结构**：使用 `page-transition-container` 模式实现平滑切换

## 预期效果
- 下一页：新建议从右侧平滑滑入，旧建议从左侧滑出
- 上一页：新建议从左侧平滑滑入，旧建议从右侧滑出
- 动画流畅，无卡顿或闪现
- 与功能页切换效果保持一致
