## 问题分析

需要调整位置的元素：
- 登录页面父容器
- 引力搜索页面父容器

不能影响的元素：
- 分类卡片内部（使用 `glass-card h-24 flex flex-col items-center justify-center`）
- 详情页内部元素（使用 `flex flex-col items-center justify-center`）
- Docker栏（使用固定定位 `nav.fixed.bottom-4`）

## 解决方案

**修改文件**：`src/css/styles.css`、`src/js/pages/galgame.js`、`src/js/pages/profile.js`

### 1. 在CSS中添加专门的父容器类
```css
/* 登录和引力搜索页面的父容器 - 向下偏移 */
.auth-page-container {
    width: 100%;
    padding: 0 1rem;
    padding-top: calc(5rem + 5vh);
    box-sizing: border-box;
    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
    min-height: calc(100vh - 5rem);
}
```

### 2. 修改JS文件
- `galgame.js`: 父容器类改为 `auth-page-container`
- `profile.js`: 父容器类改为 `auth-page-container`

这样只影响这两个特定页面，不会影响分类卡片、详情页内部元素和Docker栏。
