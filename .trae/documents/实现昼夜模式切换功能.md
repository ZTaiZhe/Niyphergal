# 实现昼夜模式切换功能

## 1. 需求分析
- 自动根据服务器时间切换昼夜模式
- 手动切换开关，位于首页左下角
- 圆形按钮，点击切换
- 白天模式显示太阳图标，夜晚模式显示月亮图标
- 按钮底层为亚克力材质（与网站现有风格一致）

## 2. 实现步骤

### 2.1 添加CSS样式
- 在现有的`<style>`标签中添加深色模式变量和样式
- 修改`body`样式，添加深色模式下的背景色和文字颜色
- 修改`glass-card`类，添加深色模式下的亚克力效果
- 添加其他组件的深色模式样式，确保整体视觉一致性

### 2.2 添加JavaScript逻辑
- 实现`getServerTime`函数，获取服务器时间判断当前时段
- 实现`toggleTheme`函数，切换主题模式
- 实现`saveTheme`和`loadTheme`函数，使用localStorage保存用户选择
- 实现`initTheme`函数，初始化主题（优先使用用户保存的主题，否则根据服务器时间自动判断）

### 2.3 添加HTML元素
- 在页面底部添加主题切换按钮，使用固定定位（fixed）放置在左下角
- 按钮使用`glass-card`类实现亚克力效果
- 按钮内容使用Remixicon图标（太阳/月亮）
- 添加事件监听器，实现点击切换功能

### 2.4 测试和优化
- 测试自动切换功能是否正常工作
- 测试手动切换功能是否正常工作
- 测试主题设置是否能正确保存和加载
- 优化深色模式下的视觉效果，确保所有组件都能正常显示

### 3.2 JavaScript逻辑添加
```javascript
// 主题切换功能
const ThemeManager = {
    // 获取服务器时间并判断当前是白天还是夜晚
    getServerTime() {
        const now = new Date();
        const hour = now.getHours();
        // 6点到18点为白天，其余为夜晚
        return hour >= 6 && hour < 18 ? 'light' : 'dark';
    },
    
    // 切换主题
    toggleTheme() {
        const body = document.body;
        const currentTheme = body.classList.contains('dark') ? 'dark' : 'light';
        const newTheme = currentTheme === 'light' ? 'dark' : 'light';
        
        body.classList.toggle('dark');
        this.updateThemeIcon(newTheme);
        this.saveTheme(newTheme);
    },
    
    // 更新主题图标
    updateThemeIcon(theme) {
        const icon = document.getElementById('theme-icon');
        if (icon) {
            icon.className = theme === 'light' ? 'ri-moon-line text-xl' : 'ri-sun-line text-xl';
        }
    },
    
    // 保存主题到localStorage
    saveTheme(theme) {
        localStorage.setItem('theme', theme);
    },
    
    // 从localStorage加载主题
    loadTheme() {
        return localStorage.getItem('theme');
    },
    
    // 初始化主题
    initTheme() {
        const savedTheme = this.loadTheme();
        const defaultTheme = this.getServerTime();
        const theme = savedTheme || defaultTheme;
        
        if (theme === 'dark') {
            document.body.classList.add('dark');
        }
        this.updateThemeIcon(theme);
    }
};
```

### 3.4 事件监听器添加
```javascript
// 初始化主题
ThemeManager.initTheme();

// 添加主题切换按钮事件监听器
const themeToggle = document.getElementById('theme-toggle');
if (themeToggle) {
    themeToggle.addEventListener('click', () => ThemeManager.toggleTheme());
}
```

## 4. 预期效果
- 网站加载时，根据服务器时间自动切换到白天或夜晚模式
- 点击左下角的圆形按钮，可以手动切换主题
- 切换主题时，按钮图标从太阳变为月亮，或从月亮变为太阳
- 主题设置会保存在localStorage中，下次访问时保持用户选择
- 深色模式下，所有组件都能正常显示，保持良好的视觉效果

## 5. 技术要点
- 使用CSS类切换实现主题切换
- 使用localStorage保存用户偏好
- 使用固定定位实现按钮悬浮效果
- 利用现有网站的亚克力材质设计，保持视觉一致性
- 确保深色模式下的所有组件都能正常显示
