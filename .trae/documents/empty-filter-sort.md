# 空状态时筛选和排序卡片显示问题修复计划

## 需求

- 无结果时调用 `renderNoResults(keyword)`，不包含筛选/排序
- `renderResultsHeader` 只在有结果时调用

## 修改方案
修改 `src/js/pages/search.js`：
- 无结果时也要显示筛选/排序（移除 disabled 状态）
- 让用户可以修改筛选/排序条件重新搜索
