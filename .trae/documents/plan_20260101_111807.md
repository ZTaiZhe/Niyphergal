# 修复移动端卡片居中对齐问题（基于DPI的方案）

## 问题分析
- 之前使用的 `left-1/2 transform -translate-x-1/2` 方式导致卡片向左偏移
- 父容器已经使用了 `flex flex-col items-center justify-center`，应该能实现居中对齐
- 卡片上的额外定位类导致了双重居中，引起偏移

## 根本原因
- 父容器已经设置了 `flex flex-col items-center`，会使子元素水平居中
- 卡片上又添加了 `left-1/2 transform -translate-x-1/2`，导致双重居中
- 这种组合在不同DPI设备上表现不一致

## 解决方案

### 文件：index.html

1. **移除卡片上的额外定位类**：
   - 从引力搜索页卡片中移除 `left-1/2 transform -translate-x-1/2` 类
   - 从登录页卡片中移除 `left-1/2 transform -translate-x-1/2` 类

2. **确保父容器居中样式生效**：
   - 保留父容器的 `flex flex-col items-center justify-center` 样式
   - 确保父容器的宽度设置正确

3. **调整卡片宽度**：
   - 确保卡片使用相对单位，如 `min()` 函数结合 `vw`
   - 保持 `.wide-card` 和 `.responsive-card` 的 `width` 设置

### 具体修改

1. **修改引力搜索页卡片**：
   - 移除 `left-1/2 transform -translate-x-1/2` 类
   - 确保卡片在flex容器中正确居中

2. **修改登录页卡片**：
   - 移除 `left-1/2 transform -translate-x-1/2` 类
   - 确保卡片在flex容器中正确居中

3. **优化CSS样式**：
   - 确保 `.wide-card` 和 `.responsive-card` 的 `margin: 0 auto` 生效
   - 考虑添加 `max-w-full` 确保卡片宽度适应不同屏幕

## 预期效果
- 引力搜索页卡片在移动端竖屏状态下能够左右居中
- 登录页卡片在移动端竖屏状态下能够左右居中
- 基于DPI的相对单位确保在各种屏幕尺寸和分辨率下都能正确对齐
- 避免使用可能导致偏移的绝对定位

## 代码修改示例

### 引力搜索页卡片
```html
<!-- 修改前 -->
<div class="glass-card wide-card flex flex-col space-y-4 left-1/2 transform -translate-x-1/2">

<!-- 修改后 -->
<div class="glass-card wide-card flex flex-col space-y-4">
```

### 登录页卡片
```html
<!-- 修改前 -->
<div class="glass-card responsive-card flex flex-col space-y-4 left-1/2 transform -translate-x-1/2">

<!-- 修改后 -->
<div class="glass-card responsive-card flex flex-col space-y-4">
```

### CSS优化
```css
.wide-card,
.responsive-card {
    /* 确保在各种屏幕尺寸下都能正确居中 */
    margin: 0 auto;
    max-w-full;
    /* 其他样式保持不变 */
}
