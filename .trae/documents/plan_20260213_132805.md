## 修改计划

### 问题分析

当前逻辑没有正确处理先决条件：
1. **先决条件**：搜索栏必须已经达到最小宽度（280px）时，才允许不居中（向右平移）
2. **间隔一致性**：搜索栏与右边界的最小间隔 = Logo 卡片与左边界的固定间隔（40px）

### 修改逻辑

```
布局计算流程：
1. 计算居中时搜索栏最大宽度 = 页面宽度 - 2*(左边界间隔 + Logo宽度 + 最小间隔)
2. 计算靠左时搜索栏最大宽度 = 页面宽度 - 左边界间隔 - Logo宽度 - 最小间隔 - 右边界最小间隔

判断逻辑：
├─ 居中最大宽度 >= 搜索栏最小宽度 → 居中显示，搜索栏可缩窄
├─ 居中最大宽度 < 搜索栏最小宽度 且 靠左最大宽度 >= 搜索栏最小宽度 → 靠左显示（搜索栏已达最小宽度）
└─ 靠左最大宽度 < 搜索栏最小宽度 → 切换移动模式
```

### 参数设置

| 参数 | 值 | 说明 |
|------|-----|------|
| `leftPadding` | 40px | Logo 与左边界固定间隔 |
| `rightMinPadding` | 40px | 搜索栏与右边界最小间隔（= leftPadding） |
| `minGapWidth` | 20px | Logo 与搜索栏最小间隔 |
| `searchMinWidth` | 280px | 搜索栏最小宽度 |
