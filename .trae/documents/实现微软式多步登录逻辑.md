## 实现微软式多步登录逻辑

### 目标
将当前的单步登录/注册表单修改为微软式的多步登录流程：
1. 第一步：仅显示邮箱输入框和"下一步"按钮
2. 第二步：根据邮箱是否已注册，显示登录或注册表单

### 实现步骤

1. **修改登录表单 UI**
   - 创建多步表单结构，包含两个步骤
   - 第一步：仅显示邮箱输入和"下一步"按钮
   - 第二步：根据邮箱状态显示登录或注册表单

2. **添加状态管理**
   - 跟踪当前步骤（1或2）
   - 保存用户输入的邮箱
   - 记录邮箱是否已注册

3. **实现步骤转换逻辑**
   - `handleEmailStep`：验证邮箱格式，检查是否已注册，转换到第二步
   - `handleLoginStep`：处理登录提交
   - `handleRegisterStep`：处理注册提交

4. **更新按钮和提示文本**
   - 根据当前步骤显示合适的按钮文本
   - 显示清晰的步骤提示
   - 更新错误信息显示

5. **优化键盘导航**
   - 确保回车键在各步骤中正常工作
   - 第一步：回车触发"下一步"
   - 第二步：回车触发登录/注册

6. **保持响应式设计**
   - 确保多步表单在各种屏幕尺寸下正常显示
   - 维持现有卡片样式和布局

### 关键代码修改

1. **更新 Pages.profile() 函数**
   - 重构登录表单为多步结构
   - 添加步骤切换逻辑
   - 更新 UI 元素和文本

2. **添加新的 Actions 方法**
   - `handleEmailStep()`
   - `handleLoginStep()`
   - `handleRegisterStep()`

3. **更新 bindPasswordCheck 函数**
   - 移除旧的单步验证逻辑
   - 添加多步表单的事件监听

4. **优化键盘事件处理**
   - 根据当前步骤调整回车键行为

### 预期效果

- 用户首先看到简洁的邮箱输入界面
- 输入邮箱后，系统智能判断显示登录或注册表单
- 提供清晰的步骤反馈和错误提示
- 保持良好的用户体验和视觉一致性
- 支持键盘导航，提高操作效率

这个修改将使登录流程更加直观和用户友好，类似于微软等主流平台的登录体验。
