# Smooth Dark/Light Mode Transition Animation Implementation Plan

## Overview
Implement a radial expansion animation that originates from the theme toggle button, replacing the current instant transition. The animation will smoothly transition between light and dark themes over 400ms.

## Implementation Steps

### 1. Update HTML Structure
- **Add animation layer**: Insert a `<div id="theme-transition">` at the end of the body, just before the closing `</body>` tag
- **Adjust toggle button z-index**: Change the toggle button's z-index to `z-[9999]` to ensure it stays above the animation layer

### 2. Add CSS Animation Styles
- **Animation layer base styles**: Fixed positioning, full viewport size, high z-index (9998), pointer-events none
- **Keyframes definition**: `themeTransition` animation that expands background-size from 0% to 200%
- **Active state**: Trigger animation when `active` class is added
- **Reduced motion support**: Media query to disable animation for users who prefer reduced motion

### 3. Modify JavaScript Theme Toggle Logic
- **Add animation state flag**: `isAnimating` property to prevent multiple concurrent animations
- **Update toggleTheme function**:
  - Check animation flag to prevent re-entry
  - Calculate toggle button's viewport coordinates using `getBoundingClientRect()`
  - Set radial gradient center to button position
  - Configure gradient color based on target theme
  - Trigger animation by adding `active` class
  - Listen for `animationend` event to complete theme transition
  - Toggle body theme class, update icon, and save theme preference after animation
  - Reset animation layer and state flag

## Technical Details

### CSS Implementation
```css
/* Theme transition animation layer */
#theme-transition {
    position: fixed;
    top: 0;
    left: 0;
    width: 100vw;
    height: 100vh;
    pointer-events: none;
    z-index: 9998;
    opacity: 0;
    transition: opacity 0s ease;
    background-position: center;
    background-repeat: no-repeat;
}

/* Animation active state */
#theme-transition.active {
    opacity: 1;
    animation: themeTransition 400ms ease-in-out forwards;
}

/* Radial expansion keyframes */
@keyframes themeTransition {
    0% { background-size: 0% 0%; }
    100% { background-size: 200% 200%; }
}

/* Reduced motion support */
@media (prefers-reduced-motion: reduce) {
    #theme-transition.active {
        animation: none;
        background-size: 200% 200%;
        opacity: 1;
    }
}
```

### JavaScript Implementation
```javascript
const ThemeManager = {
    // Add animation state flag
    isAnimating: false,
    
    // Existing methods...
    
    toggleTheme() {
        // Prevent multiple animations
        if (this.isAnimating) return;
        
        const body = document.body;
        const currentTheme = body.classList.contains('dark') ? 'dark' : 'light';
        const newTheme = currentTheme === 'light' ? 'dark' : 'light';
        
        this.isAnimating = true;
        
        // Update theme icon immediately for feedback
        this.updateThemeIcon(newTheme);
        
        // Get toggle button position
        const toggleBtn = document.getElementById('theme-toggle');
        const rect = toggleBtn.getBoundingClientRect();
        const centerX = rect.left + rect.width / 2;
        const centerY = rect.top + rect.height / 2;
        
        // Configure transition layer
        const transitionLayer = document.getElementById('theme-transition');
        const newBgColor = newTheme === 'dark' ? '#0f172a' : '#ffffff';
        
        // Set radial gradient origin and start animation
        transitionLayer.style.background = `radial-gradient(circle at ${centerX}px ${centerY}px, ${newBgColor} 0%, transparent 0%)`;
        transitionLayer.classList.add('active');
        
        // Complete transition after animation
        transitionLayer.addEventListener('animationend', () => {
            body.classList.toggle('dark');
            this.saveTheme(newTheme);
            
            // Reset animation layer
            transitionLayer.classList.remove('active');
            this.isAnimating = false;
        }, { once: true });
    },
    
    // Existing methods...
};
```

## Expected Results
- **Immediate feedback**: Theme icon changes instantly on click
- **Smooth radial expansion**: Dark/light color expands from toggle button over 400ms
- **Seamless transition**: No visible instant color changes
- **Accessibility compliance**: Respects reduced motion preferences
- **Performance optimized**: GPU-accelerated CSS animation
- **No layout shifts**: Animation layer doesn't affect page layout
