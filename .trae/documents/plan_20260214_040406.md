## 问题分析

从截图看，卡片虽然居中，但当前的居中方案过于复杂（三种方法叠加），可能导致潜在的布局冲突。

## 简化方案

**修改文件**：`src/css/styles.css`

### 核心修改

1. **移除复杂的多方法居中**：只保留一种可靠的居中方案
2. **使用Flexbox+Width限制**：
   - 父容器使用Flexbox居中
   - 卡片使用固定宽度限制 + margin: 0 auto

### 具体实现

1. **简化父容器样式**：
   ```css
   .flex.flex-col.items-center.justify-center {
       width: 100%;
       padding: 0 1rem;
       box-sizing: border-box;
       display: flex;
       flex-direction: column;
       align-items: center;
       justify-content: center;
   }
   ```

2. **统一卡片样式**：
   ```css
   .wide-card,
   .responsive-card {
       width: 100%;
       max-width: 400px;
       margin: 0 auto;
       padding: clamp(2rem, 7vw, 3rem);
       min-height: 500px;
       box-sizing: border-box;
   }
   ```

3. **移除多余的媒体查询**：
   - 移除移动端position + transform居中
   - 移除桌面端的特殊处理

这样的方案更简洁可靠，避免了样式冲突，同时确保卡片在所有设备上都能正确居中显示。
