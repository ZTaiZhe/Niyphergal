# 移动端搜索栏优化实现

## 需求分析
1. 移动端时搜索栏自动变成圆形搜索图标
2. 点击后向下弹出真正的搜索栏
3. 弹出的搜索栏需要留有左右间距和上间距，并占满页面宽度
4. 所有原有逻辑不变

## 实现方案

### 1. 修改HTML结构
- 在header中添加一个移动端专用的圆形搜索图标按钮
- 将现有搜索栏容器修改为可隐藏/显示的结构
- 添加必要的CSS类和ID用于控制显示状态

### 2. 添加CSS样式
- 使用媒体查询为移动端设计样式
- 实现圆形搜索图标的样式
- 实现搜索栏弹出/收起的动画效果
- 确保弹出的搜索栏留有适当的间距

### 3. 添加JavaScript交互
- 监听移动端搜索图标的点击事件
- 控制搜索栏的显示和隐藏
- 处理点击外部区域关闭搜索栏的逻辑
- 确保原有搜索功能不受影响

### 4. 具体实现步骤

#### 步骤1：修改header HTML结构
```html
<header class="fixed top-0 w-full z-40 px-5 py-3 flex items-center h-16 bg-transparent">
    <!-- 左上角药丸卡片菜单 -->
    <!-- ... 现有菜单代码 ... -->
    
    <!-- 移动端搜索图标 -->
    <div class="mobile-search-icon ml-auto md:hidden">
        <button id="mobile-search-btn" class="w-10 h-10 rounded-full glass-card flex items-center justify-center shadow-sm">
            <i class="ri-search-2-line text-gray-500 dark:text-gray-400"></i>
        </button>
    </div>
    
    <!-- 搜索栏容器 -->
    <div class="relative w-full max-w-2xl mx-auto flex-1" id="search-container">
        <!-- 现有搜索栏代码 -->
    </div>
</header>

<!-- 移动端搜索栏弹出层 -->
<div id="mobile-search-overlay" class="fixed top-0 left-0 w-full h-full z-30 bg-black/20 hidden"></div>
```

#### 步骤2：添加CSS样式
```css
/* 移动端搜索图标样式 */
.mobile-search-icon {
    display: none;
}

/* 移动端样式 */
@media (max-width: 768px) {
    /* 隐藏原有搜索栏 */
    #search-container {
        display: none;
        position: absolute;
        top: 100%;
        left: 5%;
        right: 5%;
        width: 90%;
        margin: 0;
        z-index: 41;
        animation: slideDown 0.3s ease-out;
    }
    
    /* 显示移动端搜索图标 */
    .mobile-search-icon {
        display: block;
    }
    
    /* 搜索栏显示状态 */
    #search-container.active {
        display: block;
    }
    
    /* 弹出动画 */
    @keyframes slideDown {
        from {
            opacity: 0;
            transform: translateY(-10px);
        }
        to {
            opacity: 1;
            transform: translateY(0);
        }
    }
    
    /* 优化搜索栏容器样式 */
    #search-container .flex.items-center.rounded-full.px-4.py-2.w-full.glass-card.shadow-sm {
        border-radius: 12px;
    }
}
```

#### 步骤3：添加JavaScript交互
```javascript
// 移动端搜索栏交互
const mobileSearchBtn = document.getElementById('mobile-search-btn');
const searchContainer = document.getElementById('search-container');
const mobileSearchOverlay = document.getElementById('mobile-search-overlay');

// 点击搜索图标显示搜索栏
mobileSearchBtn.addEventListener('click', () => {
    searchContainer.classList.add('active');
    mobileSearchOverlay.classList.remove('hidden');
    // 自动聚焦到搜索框
    setTimeout(() => {
        document.getElementById('header-search').focus();
    }, 100);
});

// 点击遮罩层关闭搜索栏
mobileSearchOverlay.addEventListener('click', () => {
    searchContainer.classList.remove('active');
    mobileSearchOverlay.classList.add('hidden');
});

// 点击搜索按钮后关闭搜索栏
const searchBtn = searchContainer.querySelector('button');
if (searchBtn) {
    searchBtn.addEventListener('click', () => {
        // 保持原有搜索逻辑
        // 关闭搜索栏
        searchContainer.classList.remove('active');
        mobileSearchOverlay.classList.add('hidden');
    });
}
```

### 5. 确保兼容性
- 确保原有桌面端搜索功能不受影响
- 确保响应式设计在不同设备上正常工作
- 确保动画效果流畅自然
- 确保触摸事件处理正确

## 预期效果
1. 在桌面端，搜索栏保持原有显示方式
2. 在移动端，搜索栏自动隐藏，只显示圆形搜索图标
3. 点击圆形搜索图标后，搜索栏从顶部向下弹出，带有平滑动画
4. 弹出的搜索栏留有左右5%的间距，上间距为header高度
5. 搜索栏占满页面宽度的90%
6. 点击遮罩层或搜索按钮后，搜索栏收起
7. 原有搜索功能和搜索联想功能保持不变

这个实现方案将确保移动端用户体验得到优化，同时保持原有功能的完整性。
