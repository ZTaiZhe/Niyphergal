# 搜索联想栏换页焦点管理优化计划

## 1. 功能修改

### 1.1 修改 `displaySuggestions` 方法
- 添加一个参数 `keepSelection`，用于指示是否保持选择状态
- 当 `keepSelection` 为 true 时，不重置 `currentIndex` 和 `isSelecting`
- 确保在保持选择状态时，`currentIndex` 被限制在当前页的范围内

### 1.2 修改 `handleKeydown` 方法中的左右箭头处理
- 在调用 `displaySuggestions` 时，传入 `keepSelection: true` 参数
- 确保翻页后焦点回到新页面的第一项

### 1.3 修改分页按钮点击事件处理
- 在分页按钮点击事件中，调用 `displaySuggestions` 时传入 `keepSelection: true` 参数
- 确保点击分页按钮后，焦点也能回到新页面的第一项

## 2. 技术实现

### 2.1 修改 `search.js` 中的 `displaySuggestions` 方法
- 添加 `keepSelection` 参数
- 根据参数值决定是否重置选择状态
- 确保 `currentIndex` 在有效范围内

### 2.2 修改 `handleKeydown` 方法中的左右箭头处理逻辑
- 更新调用 `displaySuggestions` 的方式，传入新参数

### 2.3 修改分页按钮点击事件处理逻辑
- 更新调用 `displaySuggestions` 的方式，传入新参数
