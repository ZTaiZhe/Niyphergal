## [x] Task 2: 更新路由和渲染器
- **Priority**: P0

  - 新关键词搜索 -> 使用 history.pushState（新增历史记录）
  - 页内刷新/排序/筛选 -> 使用 history.replaceState（避免用户点后退时需退几十次筛选记录）
  - 在 renderer.js 中添加搜索页的渲染逻辑
  - 实现 PageOrder 兜底逻辑：标准场景 vs 兜底场景
