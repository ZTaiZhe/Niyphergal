# 新搜索页 - Verification Checklist

## 搜索页基础功能验证
- [x] 搜索页路由正确创建，router.push('search')能正常渲染搜索页
- [x] 搜索页不包含单独的搜索栏，仅使用header的搜索栏
- [x] 搜索页能正确读取并解码URL参数中的搜索词
- [x] 搜索页能正确读取header搜索栏中的文本
- [x] 搜索结果与 Query 严格匹配，且无重复项；搜索词为空时，列表清空
- [x] 搜索页使用SearchIndex正确获取并显示搜索结果

## URL参数和刷新验证
- [x] URL中包含搜索查询参数时，搜索页能正确读取并显示结果
- [x] 刷新页面后，搜索结果不会丢失（已修复：添加了 parseInitialRoute 函数）
- [x] 搜索时URL参数被正确使用encodeURIComponent编码
- [x] 排序状态能保存到URL参数（正确编码）
- [x] 筛选状态能保存到URL参数（正确编码）
- [x] 搜索页内修改关键词使用路由器推送（新增历史记录）
- [x] 搜索页内修改筛选/排序使用路由器更换

## 浏览器历史与导航 (Browser History & Navigation)
- [x] 后退键验证（新搜索）：搜索 A -> 搜索 B -> 点击浏览器后退 -> 页面应无刷新回到 A 的结果，且 Header 输入框恢复为 "A"
- [x] 后退键验证（筛选/排序）：搜索 A -> 点击"按价格排序" -> 点击浏览器后退 -> 页面应无刷新回到"默认排序"状态，不应退回到上一个页面（如首页）
- [x] 滚动位置恢复 (Scroll Restoration)：在搜索结果页向下滚动浏览 -> 点击进入详情页 -> 点击浏览器后退 -> 页面应停留在刚才滚动的垂直位置，而不是回到顶部
